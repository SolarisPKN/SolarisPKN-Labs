# SolarisPKN-Engineer

Herramienta local y experimental para comprender proyectos de software complejos, sus archivos y las relaciones entre módulos.

Analizador local de dependencias, relaciones e impacto de cambios con grafos interactivos y documentación opcional asistida por IA.

## Alcance comprobado

- Análisis estático de código, recursos y dependencias sin ejecutar los archivos inspeccionados.
- Grafos HTML y exportación Markdown compatible con Obsidian.
- Cola de trabajo SQLite reanudable y pruebas automatizadas.
- Los resultados del análisis no garantizan que un archivo pueda eliminarse sin consecuencias.

## Integración con SolarisPKN-Labs

Este proyecto aparece en **core Labs**. Cuando SolarisPKN-Stats publique un `Stats.json` compatible, Labs mostrará las estadísticas de GitHub y de las plataformas disponibles. La ausencia de métricas no implica una caída del servicio.
