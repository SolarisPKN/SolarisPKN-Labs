# SolarisPKN-Engineer

Experimental local tool for understanding complex software projects, files and module relationships.

Local dependency and change-impact analyzer with interactive graphs and optional AI-assisted documentation.

## Verified scope

- Static analysis of source, resources and dependencies without executing inspected files.
- HTML dependency graphs and Obsidian-compatible Markdown export.
- Resumable SQLite-backed work queue and automated tests.
- Static analysis cannot prove a file is safe to delete.

## Connection to SolarisPKN-Labs

This project is listed in **core Labs**. When SolarisPKN-Stats publishes a compatible `Stats.json`, Labs displays available GitHub and optional platform metrics. Missing statistics are not evidence of downtime.
