# skills-introduction-to-github

Práctica realizada con herramientas y materiales formativos de GitHub.

Ejercicio guiado de GitHub Skills sobre ramas, commits y pull requests; no es un producto SolarisPKN.

## Alcance comprobado

- Ejercicio de aprendizaje creado por GitHub Skills.
- Workflow de práctica sobre ramas, cambios, PR y merge.
- No se presenta como software desarrollado originalmente por SolarisPKN.

## Integración con SolarisPKN-Labs

Este proyecto aparece en **external Labs**. Cuando SolarisPKN-Stats publique un `Stats.json` compatible, Labs mostrará las estadísticas de GitHub y de las plataformas disponibles. La ausencia de métricas no implica una caída del servicio.
