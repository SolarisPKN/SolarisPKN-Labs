# Figma-Lab

Design and implementation experiments using the external Figma platform.

Interface laboratory created with Figma tools; includes an experimental UI showcasing SolarisPKN-Stats concepts.

## Verified scope

- React and TypeScript UI prototype.
- Illustrative screens for GitHub, Cloudflare and PageSpeed connectors.
- The UI does not establish that those connectors run, nor does it replace SolarisPKN-Stats.

## Connection to SolarisPKN-Labs

This project is listed in **external Labs**. When SolarisPKN-Stats publishes a compatible `Stats.json`, Labs displays available GitHub and optional platform metrics. Missing statistics are not evidence of downtime.

Source repository: [Figma-Lab](https://github.com/SolarisPKN/Figma-Lab)
