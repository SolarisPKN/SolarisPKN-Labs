# Figma-Lab

Experimentos de diseño e implementación con una plataforma externa: Figma.

Laboratorio de interfaces creado con herramientas de Figma; contiene una interfaz experimental para visualizar componentes de SolarisPKN-Stats.

## Alcance comprobado

- Prototipo de interfaz React y TypeScript.
- Pantallas ilustrativas de conectores GitHub, Cloudflare y PageSpeed.
- La interfaz no acredita la ejecución de esos conectores ni sustituye a SolarisPKN-Stats.

## Integración con SolarisPKN-Labs

Este proyecto aparece en **external Labs**. Cuando SolarisPKN-Stats publique un `Stats.json` compatible, Labs mostrará las estadísticas de GitHub y de las plataformas disponibles. La ausencia de métricas no implica una caída del servicio.

Repositorio de código: [Figma-Lab](https://github.com/SolarisPKN/Figma-Lab)
