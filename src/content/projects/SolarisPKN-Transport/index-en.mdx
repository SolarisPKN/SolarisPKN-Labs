# SolarisPKN-Transport

Reusable infrastructure for keeping transport websites supplied with trustworthy schedules even when upstream services fail.

Transport timetable pipeline using SOFSE, Cuándo SUBO and GTFS connectors, data validation, and XLSX, CSV and SQLite outputs.

## Verified scope

- Modular train and bus timetable connectors.
- Validation before replacing trusted workbooks and databases.
- XLSX, CSV and SQLite exports with provenance.
- Explicit separation of scheduled times and live vehicle tracking.

## Connection to SolarisPKN-Labs

This project is listed in **core Labs**. When SolarisPKN-Stats publishes a compatible `Stats.json`, Labs displays available GitHub and optional platform metrics. Missing statistics are not evidence of downtime.
