# SolarisPKN-Transport

Infraestructura reutilizable para alimentar sitios de transporte con horarios confiables, incluso ante fallos de servicios externos.

Pipeline de horarios de transporte con conectores SOFSE, Cuándo SUBO y GTFS, validación de datos y salidas XLSX, CSV y SQLite.

## Alcance comprobado

- Conectores modulares de horarios ferroviarios y colectivos.
- Validación antes de reemplazar planillas y base de datos confiables.
- Exportación XLSX, CSV y SQLite con procedencia de datos.
- Separación explícita entre horarios programados y seguimiento en vivo.

## Integración con SolarisPKN-Labs

Este proyecto aparece en **core Labs**. Cuando SolarisPKN-Stats publique un `Stats.json` compatible, Labs mostrará las estadísticas de GitHub y de las plataformas disponibles. La ausencia de métricas no implica una caída del servicio.
