# SolarisPKN-Arts

Espacio dedicado a piezas y recursos de identidad visual del ecosistema.

Repositorio de recursos visuales y arte de la identidad SolarisPKN; su documentación pública todavía es mínima.

## Alcance comprobado

- Repositorio de recursos gráficos versionados.
- La documentación disponible todavía no describe una aplicación instalable ni servicios públicos.

## Integración con SolarisPKN-Labs

Este proyecto aparece en **core Labs**. Cuando SolarisPKN-Stats publique un `Stats.json` compatible, Labs mostrará las estadísticas de GitHub y de las plataformas disponibles. La ausencia de métricas no implica una caída del servicio.
