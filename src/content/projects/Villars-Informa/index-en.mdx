# Villars-Informa

Independent SolarisPKN-derived project sharing practical information about Villars and nearby areas.

Villars community portal with news, services, vector maps and published transport information.

## Verified scope

- Astro-based static community website.
- PMTiles vector maps organized by Buenos Aires Province district.
- Consumes timetable exports from SolarisPKN-Transport.
- The frontend is not the provider of live transport collection.

## Connection to SolarisPKN-Labs

This project is listed in **derived Labs**. When SolarisPKN-Stats publishes a compatible `Stats.json`, Labs displays available GitHub and optional platform metrics. Missing statistics are not evidence of downtime.
