# Villars-Informa

Proyecto independiente nacido del ecosistema SolarisPKN para ofrecer información útil de Villars y alrededores.

Portal comunitario de Villars con noticias, servicios, mapa vectorial e información de transporte basada en datos publicados.

## Alcance comprobado

- Sitio comunitario estático desarrollado con Astro.
- Mapas vectoriales PMTiles por partido bonaerense.
- Consumo de datos de horarios generados por SolarisPKN-Transport.
- El frontend no es el servicio que genera el seguimiento de transporte en vivo.

## Integración con SolarisPKN-Labs

Este proyecto aparece en **derived Labs**. Cuando SolarisPKN-Stats publique un `Stats.json` compatible, Labs mostrará las estadísticas de GitHub y de las plataformas disponibles. La ausencia de métricas no implica una caída del servicio.
