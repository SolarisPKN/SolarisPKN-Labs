# SolarisPKN-IA

The open blueprint describing the architecture and design principles behind SolarisPKN-IA.

Public architecture and reference examples for building a modular, privacy-first local AI assistant.

## Verified scope

- Public blueprint documenting capabilities, security and modules.
- Reference examples for tool contracts, policies and learning.
- The public repository does not contain or distribute the private Solaris runtime.

## Connection to SolarisPKN-Labs

This project is listed in **core Labs**. When SolarisPKN-Stats publishes a compatible `Stats.json`, Labs displays available GitHub and optional platform metrics. Missing statistics are not evidence of downtime.
