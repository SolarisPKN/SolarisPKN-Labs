# SolarisPKN-IA

La versión abierta de la arquitectura y principios de diseño del sistema SolarisPKN-IA.

Arquitectura pública y ejemplos de referencia para construir un asistente de IA local, modular y orientado a la privacidad.

## Alcance comprobado

- Blueprint público con documentación de capacidades, seguridad y módulos.
- Ejemplos de contratos, políticas, aprendizaje y herramientas.
- El repositorio público no contiene ni distribuye el runtime privado Solaris.

## Integración con SolarisPKN-Labs

Este proyecto aparece en **core Labs**. Cuando SolarisPKN-Stats publique un `Stats.json` compatible, Labs mostrará las estadísticas de GitHub y de las plataformas disponibles. La ausencia de métricas no implica una caída del servicio.
